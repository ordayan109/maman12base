ממ״ן 12 בקורס 20407 — קובצי הקופסה השחורה

יש לבחור שפה אחת בלבד. בכל שפה ממומשים אותם ארבעה אלגוריתמים A–D ואותה שיטת ספירה.

Python 3.10 ומעלה
1. השאירו את black_box.py ואת starter.py באותה תיקייה.
2. הריצו: python starter.py
3. הקריאה היא run("A", data). אפשר להחליף את A באחד הסימנים B, C או D.

Java 17 ומעלה
1. השאירו את BlackBoxAlgorithms.java ואת Starter.java באותה תיקייה.
2. הידור: javac BlackBoxAlgorithms.java Starter.java
3. הרצה: java Starter
4. הקריאה היא BlackBoxAlgorithms.run('A', data).

C++17 ומעלה
1. השאירו את black_box.cpp ואת starter.cpp באותה תיקייה.
2. הידור: g++ -O2 -std=c++17 starter.cpp -o starter
3. הרצה בלינוקס או ב-macOS: ./starter
4. הקריאה היא run_algorithm('A', data).

תוצאת כל הרצה כוללת את המערך הממוין, מספר ההשוואות בין ערכי המערך, מספר הכתיבות לתאי מערך וזמן הריצה בננו-שניות. העתקת הקלט לפני תחילת המדידה אינה נכללת בזמן הריצה.

אין לשנות את קובץ הקופסה השחורה ואין להגישו. יש להרחיב את קובץ ההתחלה או לכתוב תוכנית ניסוי נפרדת בהתאם להוראות המטלה.
